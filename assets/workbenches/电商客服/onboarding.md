# 电商客服

# 三步上手
- 打开工作区文件夹（文档/鲸坞工作台/电商客服/），把你店里的话术放进 话术库/。用 Excel 建两列「问题」「答案」，另存为 CSV（UTF-8）放进去；也可以照 示例-话术表.txt 的格式直接写文本。示例话术全部是虚构演示数据，正式使用前请删除或换成自己的。
- 点左侧「开工上岗」，等它回复「电商客服已上岗」。
- 千牛来了买家消息：你手工复制并先脱敏，再粘到对话框；拿到【草稿】【依据】【风险】三段后，由你决定是否复制【草稿】回千牛发送。

# 粘贴前先脱敏
- 买家昵称改成「买家A/B」。
- 订单号只留尾号 4 位。
- 手机号和地址整段删除。
- 你粘贴的买家问题和店铺话术会被交给 AI 处理；涉密内容能不能放进来，请你自己判断。

# 三条纪律
- 它只出草稿，没有发送能力，发不发永远由你决定。
- 它答不了的题点「把这题登记为缺料」，你补一行话术，它下次才能答。
- 「收录这条」「批量喂」只进待入库候选；人工确认后，才手动搬进正式话术表。
