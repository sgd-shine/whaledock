# 短视频创作台

这个工作台把一条片子从选题到开拍拆成了 5 步，每一步一个按钮。

# 先做一件事
往 01_选题库 里丢东西。想到的点子、刷到的对标视频、用户说过的原话，一句话也算。
左边五个按钮全都靠这个文件夹吃饭，它空着的话第一个按钮会直接问你要素材。

装包时已经放了三个「示例-」开头的文件。先拿示例试一次，看看产出长什么样，
再换成你自己的——那三个文件删掉就行，它们只是样子。

# 五个按钮的顺序
- 今天做什么 → 从你的选题库里挑三个能今天开拍的
- 写脚本 → 选一个，出分镜
- 转口播稿 → 把分镜里的台词改成能直接念的
- 出封面标题 → 一次给 5 个，标注钩子类型
- 列素材清单 → 这条片子要拍什么、录什么屏，逐条列

# 三件要知道的事
- 每一步的结果都会存成文件夹里的真实文件，你随时能改。
- 同名文件永远不会被覆盖，会自动加 -2、-3。
- agent 干活时不用盯着窗口，托盘的鲸鱼会告诉你到哪一步了。
