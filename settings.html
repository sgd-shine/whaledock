第一次连接：照着三步做

这是给每位鲸坞用户的自助向导

你在自己的平台后台建应用，把凭据只交给本机鲸坞，再用自己的账号发首条消息完成绑定。鲸坞官方永远不经手任何用户凭据。

飞书：自建应用 → 本机保存凭据 → 绑定本人
  1. 1. 建自建应用

    在 open.feishu.cn/app 创建企业自建应用并启用机器人。只申请 im:message.p2p_msg:readonly 与 im:message:send_as_bot；先不要申请群聊或联系人权限。

  2. 2. 保存凭据并接长连接

    从“凭证与基础信息”抄 App ID / App Secret 到下方，点“保存并连接”；再回事件订阅选择长连接并添加 im.message.receive_v1，发布版本并完成企业审核。

  3. 3. 发消息并确认

    用本人飞书私聊机器人发首条消息。手机会先收到六位绑定码，再回桌面核对并确认；其他账号的消息会静默丢弃。

App Secret 不进入普通设置、日志、错误文案或公开仓库；保存后输入框立即清空。鲸坞官方永远不经手任何用户凭据。
钉钉：内部应用 → 本机保存凭据 → 绑定本人
  1. 1. 建内部应用

    在你自己的钉钉开发者后台创建企业内部应用，启用机器人和 Stream 模式。

  2. 2. 抄 Client ID / Secret

    平台接通后，这里会出现本机凭据框；凭据只留在你的电脑上，鲸坞官方看不到。

  3. 3. 发消息并确认

    用本人钉钉发首条消息，再回桌面确认绑定；绑定前不会收进工作区。

随身网页：同一 Wi-Fi 默认可用，出门再选 Tailscale
  1. 1. 连同一 Wi-Fi

    手机和电脑在同一个可信局域网，无需安装其他 App。

  2. 2. 开启并扫码

    网页通道接通后会生成带随机令牌的二维码/一次性链接，只绑定局域网接口。

  3. 3. 用完随时断开

    令牌鉴权；“全部断开”会关闭开关并请求停止监听，未确认时会明确提示。

可选：Tailscale。它会把你的手机和电脑拉进同一个虚拟局域网，出门也像在家里连。网页通道可检测并引导本机安装；注册、登录和设备授权必须由你本人在官方页面完成。

常见问题

macOS 提示无法验证开发者

当前版本未签名。首次启动请在“访达”中右键鲸坞，选择“打开”，再确认一次。

Windows 出现 SmartScreen 提示

当前版本未签名。确认文件来自官方 Releases 后，点“更多信息”→“仍要运行”。

首启较慢，或提示端口被占用

首次准备后端可能需要几分钟；若端口被其他程序占用，请到“后端”标签改端口并重启后端。
