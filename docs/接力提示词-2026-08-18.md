## 任务 A：发布 v0.5.1（修复 macOS「已损坏」）— 最优先

```
你在 whaledock 仓库（鲸坞 WhaleDock，非官方 DeepSeek Harness 桌面客户端）接力。

动手前必读，一条不许放松：
- AGENTS.md 全文（硬性约束 1–9、已知的坑、发布口径）
- docs/开发方案-第三阶段-2026-08-18.md 第 1 节
- docs/公证接入指南-2026-08-18.md

背景：v0.5.0 的 macOS 包完全没有代码签名（CSC_IDENTITY_AUTO_DISCOVERY=false 让
electron-builder 跳过了签名，产物里没有 Contents/_CodeSignature/CodeResources）。
本机构建能开，但从 GitHub 下载后被打上 com.apple.quarantine，Gatekeeper 校验包级签名失败，
Apple Silicon 上直接报「文件已损坏，应移到废纸篓」，且右键「打开」救不回来。
已有真实用户（日本，M5 Mac）踩到。

工作区里已经完成的改动（未提交）：
- 新增 scripts/macos-codesign.js（afterPack 钩子，默认 ad-hoc 签名，有 Developer ID 时自动升级）
- 新增 build/entitlements.mac.plist
- 新增 test/macos-codesign-smoke.js（19 项）
- 改 package.json（afterPack 钩子、mac.identity=null、版本 0.5.1、新增 sign:mac / verify:mac 脚本）
- 改 .github/workflows/release.yml（可选证书导入、产物签名复验硬门、可选公证、Release 说明改写）
- 改 README.md、新增 docs/macOS-安装与已损坏提示.md（中/英/日）
- 改 test/smoke.js（接入新直测 + 2 项打包合约）、test/main-v05-smoke.js（版本断言改为 0.5.x 线）

你的任务：
1. 先跑 `npm run smoke`，必须 ALL PASS（已在无 GUI 环境验证过一次，你要独立复跑）。
2. 逐文件复核上述改动，重点审：
   - scripts/macos-codesign.js 不 require Electron，纯函数可被 smoke 加载；
   - 签名顺序是「单体 Mach-O（深的优先）→ 嵌套 bundle（深的优先）→ 外层 .app」；
   - 符号链接（framework 的 Versions/Current）被跳过，不重复签名；
   - 缺 _CodeSignature 时 verifyApp 必须抛错（fail-closed）；
   - release.yml 的签名复验步骤是解压真实 zip 产物后校验，不是校验中间目录。
3. **在 Apple Silicon 本机跑一次真实打包验证**（这是必须的，因为签名逻辑无法在 Linux 上验证）：
   npm run bundle:dsh -- --platform=darwin --arch=arm64
   npx --no-install electron-builder --mac dmg zip --arm64 --publish never
   然后回读：
   - 构建日志里有 MACOS_CODESIGN_DONE
   - codesign --verify --strict --verbose=2 对解压出来的 .app 通过
   - codesign -dv --verbose=4 能看到 Signature=adhoc
   - 真实安装到 /Applications 后能正常启动、能拉起 dsh、能退出干净
   - 用 `xattr -w com.apple.quarantine "0081;00000000;Safari;" ` 给 dmg 打上隔离属性后再装一遍，
     确认提示是「无法验证开发者」而不是「已损坏」——**这是本次修复的验收核心**
   如果这一步失败，不要硬发，把 codesign 的完整错误贴出来，先修再发。
4. 配置 git 提交邮箱为 noreply 邮箱（账号开了阻止暴露邮箱推送，不配会被拒），提交信息用英文。
5. 三平台 CI 绿之后打 tag v0.5.1，走既有 Release 流程：
   审批门 WHALEDOCK_BUNDLED_COMPLIANCE_APPROVAL 按精确 tag + 产物集 SHA-256 临时设置，
   Release 与八项资产回读确认后**立即删除该变量并回读为空**。
6. 汇报：改动文件清单、smoke 实际通过数、本机打包与隔离属性验收的逐项结果、
   CI/Release 链接、仍需 SGD 人工完成的事项。

绝对不要做的事：
- 不要买证书、不要用任何付费服务、不要碰 SGD 的 Apple 账号（AGENTS.md 硬约束）。
  ad-hoc 签名不需要证书也不花钱，这是允许的；Developer ID 通道只是预埋，没有 secret 时自动不走。
- 不要写入、迁移或清理 ~/.dsh。
- 不要把「CI 构建成功」写成「真机验证通过」。
```
