# 鲸坞主题制作指南

一句话：**一个主题就是一个 JSON 文件，改 7 个颜色值就是一套新皮肤。**

## 一、四步做一套主题

1. 打开鲸坞 → 设置 → **外观与宠物** → 点「打开主题文件夹」。
2. 新建一个文件，名字随你，比如 `mytheme.json`（文件名去掉 `.json` 就是主题 id）。
3. 把下面这段粘进去，改颜色。
4. 回设置点「重载主题」，在下拉里选中它，**立即生效**。

```json
{
  "name": "我的主题",
  "author": "你的名字",
  "base": "dark",
  "colors": {
    "background": "#090e17",
    "surface": "#101a2c",
    "border": "#1e2a5e",
    "primary": "#4f46e5",
    "accent": "#22d3ee",
    "text": "#e6edf7",
    "textMuted": "#93a4bd"
  }
}
```

## 二、七个颜色分别管什么

| 键 | 管什么 | 挑色建议 |
| --- | --- | --- |
| `background` | 窗口最底层的背景 | 深色主题选最暗的那个色 |
| `surface` | 卡片、面板的底色 | 比 background 略亮一档 |
| `border` | 分隔线、描边 | 介于背景和文字之间 |
| `primary` | 主按钮、强调元素 | 你的品牌色 |
| `accent` | 高亮、数字、链接 | 和 primary 拉开色相 |
| `text` | 正文文字 | 和 background 至少 7:1 对比度 |
| `textMuted` | 次要说明文字 | 至少 4.5:1 对比度 |

`base` 只有 `dark` 和 `light` 两个值，决定整体明暗基调（滚动条、阴影等跟着走），默认 `dark`。

颜色写 `#RGB` 或 `#RRGGBB` 都行，大小写不限。

## 三、容错规则

- 某个颜色写错（比如写成 `red` 或漏了 `#`）→ **只有那一个键回落**到同基调的内置值，其余照用。
- 整个文件 JSON 语法错 → 跳过这个主题并写日志，其他主题不受影响。
- 多余的键会被忽略，方便你以后加注释字段。
- 主题文件**只被当作数据解析，里面的任何内容都不会被执行**。

设置页会显示「有 N 个主题文件被跳过」，原因去日志文件夹看。

## 四、作用范围（重要）

主题只作用于**鲸坞自己的界面**：启动页、设置窗、任务看板、截图与图片窗、战报卡片。

**不会改动 Harness 网页本身**——那是 dsh 引擎的界面，鲸坞不往里注入任何样式或脚本。这是鲸坞的硬约束，不是没做。

战报卡片自带深/浅两套配色。只有当你选的主题基调与导出的战报基调一致时（都是深色或都是浅色），主题色才会套上去，避免出现半套皮肤。

## 五、内置四套可以直接抄

`assets/themes/` 下有：

- `whaledock-dark.json` —— 鲸坞深色（出厂默认，品牌色 `#1e2a5e` / `#4f46e5` / `#22d3ee`）
- `whaledock-light.json` —— 鲸坞浅色
- `aurora.json` —— 极光（青绿 + 紫）
- `ink-whale.json` —— 墨鲸（纯灰阶）

最省事的做法：把其中一个复制到主题文件夹，改个 `name` 和几个色值就完事。

## 六、分享你的主题

欢迎提 PR 到 `community-themes/`：

1. Fork 本仓库，把你的 `xxx.json` 放进 `community-themes/`。
2. PR 标题写「community-theme: 你的主题名」。
3. 建议在 PR 里附一张设置窗截图，方便别人挑。

请确保配色是你自己搭的，不要直接搬运他人受版权保护的设计系统色板。
