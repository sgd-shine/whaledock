# 鲸坞 WhaleDock 第二阶段总验收清单

日期：2026-08-16 · 覆盖 v0.3 / v0.4 / v0.5 三个已发布版本

这份清单是给 SGD 的**人工体验项**，不阻塞发布。全部做完约 5 分钟，正好可以边拍视频边验。

每一项后面标了它当前的证据状态：

- ✅ 已有自动化或源码态证据（但仍建议你亲眼看一次）
- ⚠️ **只有代码/日志证据，没有人工看过** —— 这些是这份清单真正要解决的
- ❌ 明确未做，且本阶段不做

## 准备（30 秒）

1. 从 [Releases](https://github.com/sgd-shine/whaledock/releases) 下载 `v0.5.0` 的 arm64 dmg，拖进「应用程序」。
2. 首次打开：**右键 WhaleDock → 打开 → 打开**（未签名未公证，这是预期摩擦）。

## 一、通知长什么样（约 40 秒）⚠️

1. 在鲸坞里给 AI 一个会跑一会儿的任务，切到别的 App。
2. 任务结束时看：有没有系统通知？没有的话 Dock 图标有没有弹跳、有没有红色数字角标？托盘有没有变化？
3. 回到鲸坞主窗口，看有没有应用内横幅。

**要确认的**：至少有一条降级链路真的可见。macOS 未签名期系统通知可能被拒，这时 Dock 角标 + 托盘 + 横幅就是预期表现，**不算 bug**。

## 二、看板数字（约 30 秒）✅

1. 托盘或菜单 →「任务与用量看板…」。
2. 看今日/本周的 token 数字、按会话明细、以及顶部那句「dsh 已观测用量，非账单」。
3. 托盘 tooltip 上的今日消耗数字对不对得上。

**注意**：标题生成等旁路消耗测不到，所以这个数字天然低于真实账单——文案已经写明，不要当成 bug。

## 三、生成一张战报（约 40 秒）⚠️

1. 看板窗里点生成战报，深色试一次、浅色试一次。
2. 保存出来的 PNG 应该是 1080×1440。
3. **重点看对比度和中文排版**：v0.3 留下的两张样张是对比度修复前的，修复后的实际色彩还没人看过。
4. 再点一次「复制」，去别处粘贴，确认剪贴板里真的是图。

## 四、切一次工作区（约 40 秒）✅

1. 菜单或托盘 →「工作区」→「打开新文件夹…」，选一个目录。
2. 看主窗口标题是否变成新工作区名。
3. 切回上一个工作区（最近列表里应该有）。
4. 在 AI 里让它 `ls` 一下，确认它确实在新目录里干活。

**注意**：工作区只是 dsh 的默认 cwd，**不是文件读取沙箱**——AI 用绝对路径仍能读到别处。这是已知边界，不是漏洞。

## 五、截一张图走完整链（约 60 秒）⚠️

这是 v0.4 唯一没走完的全量链路，最值得你亲手过一遍：

1. 按 `Cmd+Shift+S`，框选屏幕上一段**带文字**的内容。
2. 预览窗出现后，第一次确认 → 图片应保存到当前工作区的 `鲸坞截图/`，界面显示真实路径。
3. 等本地 OCR 出文字，检查识别结果对不对。
4. 第二次确认 → 提交到选定会话，或降级为复制到剪贴板。
5. 去会话里确认文字真的进去了（**这一步至今没有人做过**）。
6. 再试一次拖图进窗口和粘贴剪贴板两个入口。

## 六、开一次宠物（约 60 秒）⚠️

v0.5 的主功能，目前只有启动日志证据，**动效一次都没人看过**：

1. 设置 →「外观与宠物」→ 打开「显示桌面宠物」。
2. 看宠物是否出现在右下角，背景是否真的透明（不是一个黑方块）。
3. 空闲时应缓慢上下漂浮 + 轻微呼吸缩放。
4. 给 AI 一个任务，看它是否切到「干活中」（动得更快、左右摇摆）。
5. 触发一次需要你批准的操作，看它是否「等你拍板」（定点晃动）。
6. 任务完成看它弹跳一次。
7. 拖动它换位置；右键弹出菜单，换一只宠物（内置有「像素鲸鱼」和「极简鲸鱼」两只）。
8. 打开「鼠标穿透」，确认点击能穿过去；**此时用托盘 →「桌面宠物」**把它关掉（右键菜单这时点不到，这是预期）。

**顺手验一下零门槛路径**：点「打开宠物文件夹」，新建一个文件夹丢一张任意 PNG 进去，回来点「重新扫描」，选中它——**一张图就应该会动**。这是本版最大的传播点，值得录进视频。

## 七、换一套皮肤（约 30 秒）⚠️

1. 设置 →「外观与宠物」→「皮肤主题」下拉，依次试鲸坞深色 / 浅色 / 极光 / 墨鲸。
2. 确认设置窗、启动页、看板窗、截图窗跟着变色。
3. 确认 **Harness 网页本身没有变** —— 引擎的脸不动是设计，不是漏做。
4. 点「打开主题文件夹」，复制一份内置 JSON 改几个色值，点「重载主题」看是否出现。

## 八、更新提醒（约 20 秒）⚠️

1. 设置 → 通用 →「立即检查」。
2. 装的是 v0.5.0 应显示「当前已是最新版本」。
3. 如果你手上还有旧版本安装包，装旧版再检查一次，看提醒是否出现——**线上真实 Release 的更新提醒至今没验过**。

## 九、退出干净（约 20 秒）✅

1. 完全退出鲸坞。
2. 终端跑 `lsof -ti :3080`，如果鲸坞是自己拉起 dsh 的，应该没有残留。
3. 如果是 attach 到你自己已经开着的 dsh，**它应该继续活着**——鲸坞不停外部进程。

## 明确不做的（❌）

- macOS/Windows 代码签名与 Apple 公证：需要付费开发者账号与证书，属于要你拍板的事项，本阶段不做。
- Windows 与 Intel Mac 真机验收：本阶段全线未做，Windows 按「实验性支持（未真机验证）」发布。
- 并行多开（独立端口 / 多后端 / 多主窗口）：P2，未实现。
- 官方视觉 API：上游尚未开放，代码里只留了可探测槽位。
