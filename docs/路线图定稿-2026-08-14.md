## 四、Token 看板 + 预算熔断（范围定稿）

**痛点一句话**：Agent 在后台烧钱，用户既看不见每个任务花了多少，也拦不住它烧过头。

**普通用户怎么用**：菜单栏常驻今日消耗数字；点开看板见每个任务的 token 明细与 ¥ 换算、日/周趋势；设一个预算上限，超了 App 自动暂停后端并通知，点一下恢复。

**已查证的生态事实**：社区已有网页内浮窗插件 dsh-token-stats（按会话/按模型统计，作者称官方自带统计"太粗"），证明会话级用量数据本地可得；但**桌面级方案与熔断机制全生态空缺**，这是我们的差异位。

**侦察任务（v0.2 期间并行，给 Codex 约 2 小时）**：① 找到 Harness 本地会话记录的存放位置与格式，确认是否含逐条 usage（输入/输出/缓存 token）；② 研究 dsh 插件接口与 dsh-token-stats 的数据来源，评估"写一个小 dsh 插件把用量事件推给桌面端"的可行性；③ 确认 dsh 是否支持自定义 API base URL（本地代理兜底路线的前提）；④ 确认 DeepSeek 开放平台余额查询接口的现状。产出：各路线的数据字段样例 + 推荐路线一句话。拿到结论后由 Claude 出精确实施方案。

## 五、多工作区管理（设计草案，实施前再细化）

**痛点一句话**：现在后端默认在用户主目录里干活，换项目要手动改 JSON 配置——普通用户既不知道 AI 在哪个文件夹干活，也不敢让它在整个家目录里乱动。

**普通用户怎么用**："工作区"= AI 的工位。首次启动自动创建专属文件夹（如 `~/Documents/Harness工作台/默认工作区`），不再默认用主目录（顺带是安全改进）；菜单和托盘有"工作区"子菜单：最近列表一键切换（切换 = 自动重启后端指向新文件夹）、"打开新文件夹…"；窗口标题显示当前工作区名。进阶（同版本或拆小版本）：并行多开——每个工作区独立端口（自动从 3081 递增分配）独立窗口，托盘显示各实例状态。
