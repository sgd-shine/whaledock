# DSH 能力测试：像素鲸鱼小游戏《小鲸鱼闯深海》

> 一句话：让鲸坞里跑的 DeepSeek Harness 亲自打一次工——从零做一个双击就能玩的像素小游戏，分三轮考它，看这台"发动机"的真实马力。

## 为什么这么设计

只发一句"给我做个游戏"测不出 Agent 的能力，那只是考"代码生成"。真正的 Agent 能力是三件事：**一次做对、听懂追加需求不翻车、把外行的模糊描述翻译成修复**。所以测试分三轮，一轮考一件事。三轮全程你不需要看一行代码，每轮的验收都是"双击打开玩一下"。

顺带：三轮结构天然就是视频叙事——"我做了个 DeepSeek 桌面客户端，现在让它给自己打工，我还要故意刁难它"。

## 怎么测

在鲸坞（WhaleDock）里打开对话，按顺序发下面三段提示词。**每轮之间必须真的去玩一下**，玩完再发下一轮——第二、三轮的效果取决于第一轮的成品真实存在。

---

## 第一轮：从零开发（考"一次做对"）

复制发送：

```
请给我做一个像素风网页小游戏《小鲸鱼闯深海》，要求如下：

【产出物】
- 在当前目录新建文件夹 whale-game，里面只放一个 index.html 文件
- 所有代码（HTML/CSS/JS）都写在这一个文件里，不联网、不装任何依赖，双击就能在浏览器里玩

【玩法】
- 玩家控制一只像素小鲸鱼在深海里游动：按住空格键（或鼠标点住/手指按住）向上游，松开自然下沉
- 从右往左不断出现障碍物（珊瑚柱、暗礁），碰到就游戏结束
- 海里漂着小鱼，吃到一条加 10 分；随时间难度渐渐变高（障碍更密、速度更快）
- 有开始界面（游戏标题 + 操作说明）和结束界面（本次得分 + 历史最高分 + 重新开始按钮）

【画面】
- 像素风（pixel art），用 Canvas 绘制，帧率流畅
- 主色调用深海蓝紫色系：#1e2a5e、#4f46e5、#22d3ee、#a5f3fc
- 小鲸鱼要可爱，游动时会摆尾巴；背景有气泡缓缓上升

【完成标准】
做完后请自己检查一遍：
1. 双击打开不报错，空格或点击能开始游戏
2. 碰到障碍会结束、能重新开始、历史最高分刷新页面后还在
3. 连续玩 30 秒，能明显感觉到难度在上升
检查完之后，告诉我 index.html 的完整路径。
```

**验收：** 按它给的路径找到 index.html，双击打开玩两局。找不到文件夹就直接问它："你把文件建在哪里了？给我完整路径。"（一般在个人文件夹下的 whale-game 里。）

## 第二轮：追加功能（考"迭代不翻车"）

第一轮验收通过后，接着发：

```
游戏不错，现在加三个功能：
1. 无敌冲刺：累计吃到 5 条鱼后，小鲸鱼获得 2 秒无敌状态，期间撞障碍不死，要有明显的视觉提示（比如全身发光）
2. 音效：吃鱼、撞击、进入无敌各有不同的提示音。不许用任何外部音频文件，请用代码直接生成声音
3. 暂停：按 P 键或点击暂停按钮，画面定格并显示"已暂停"，再按一次继续
全部改动仍然保持在原来那一个 index.html 文件里。
```

**验收：** 三个新功能都试一遍，然后**把第一轮的老功能再全部试一遍**——计分、重开、最高分是否还正常。加新功能弄坏老功能，是 Agent 最常见的翻车方式。

（"不许用外部音频文件"是故意设的考点：逼它用代码合成声音，这是区分"会抄模板"和"真有本事"的题。）

---

## 第三轮：模糊描述修问题（考"听得懂人话"）

先真的玩几局，然后用你自己的话描述体验问题。如果没别的不满，就发这段：

```
我玩了几局，有两个问题：
1. 手感不对：小鲸鱼往上游的时候太"窜"了，一按就飞出去，很难精细控制，帮我调到手感舒服
2. 我在手机浏览器上打开，画面挤成一团没法玩
请你自己找原因修好。改完用大白话告诉我：你改了哪几处、各是为什么。
```

**验收：** 电脑上玩起来是否顺手了；再用手机打开试一次（或把浏览器窗口拖窄模拟）。它的解释你能不能听懂，本身就是评分项。

| # | 考察点 | 0 分 | 1 分 | 2 分 |
|---|--------|------|------|------|
| 1 | 一次成型：第一轮双击就能玩 | 打不开/报错 | 催了一次才好 | 直接能玩 |

| 3 | 完成度：要求的功能一个不少 | 缺两个以上 | 缺一个 | 全齐 |
| 4 | 迭代不翻车：第二轮后老功能完好 | 老功能坏了 | 小瑕疵 | 完好 |
