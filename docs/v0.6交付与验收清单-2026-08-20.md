## 一、这一版到底做成了什么

鲸坞从「一个能开 Harness 的壳」变成「一个可以停不同船的坞」。

一个工作台包就是一个文件夹，里面只有 JSON / Markdown / PNG。**鲸坞永远不执行它们。**
拖进窗口就装好，点一下就切过去，界面、宠物、常用按钮、文件夹跟着整套换。

## 三、SGD 人工验收清单

打 ☐ 的都需要你本人在真机上做一遍，自动化替代不了。

### A. 装与切

- ☐ **真机拖装一个包**：随便复制 `assets/workbenches/短视频创作台/` 到别处改个名，拖进鲸坞窗口，看是不是一步装好、立刻出现在切换器里。
- ☐ **拖一个坏的进去**：删掉 `manifest.json` 再拖，应该明确拒绝并说原因，不是默默没反应。
- ☐ **轻工作台切一次**：切到「默认工作台」，应该**瞬间完成、后端不重启、什么都不弹**。
- ☐ **重工作台切一次并量耗时**：切到「短视频创作台」，第一次会弹一次确认卡（作者/许可证/要建的文件夹/要换的东西/重启提示），点「启用」。
  参考值：本机实测 **约 2.6 秒**（08:40:56 建目录 → 08:40:59 切换完成），远低于 5 秒线。
  你的机器上如果超过 5 秒，左栏会显示「正在切换…」并禁用按钮。
- ☐ **再切回去**：第二次不该再弹确认卡。
- ☐ **⌘⇧1 / ⌘⇧0**：菜单栏「工作台」里的加速键。注意 macOS 上 **⌘⇧3/4/5 是系统截屏，抢不过来**，所以第 3/4/5 个工作台的加速键在 macOS 上不会生效（见第五节）。
- ☐ **切换器里的坏包**：故意放一个坏包，确认切换器底部有灰色的「⚠ 包名　未加载：原因」。

### B. 五个按钮

- ☐ **五个按钮各点一遍**，看产出是不是落进 `文稿/鲸坞工作台/短视频创作台/` 对应文件夹。
  本机已经全部点过一遍，五次都返回 `accepted`。
- ☐ **D-3：把 `01_选题库` 改名后再点按钮**，看 agent 是不是老实说找不到。
  本机已经意外验证过一次（按钮发到了一个工作目录不对的会话）：agent 的思考链是
  「`01_选题库/` 不在这个工作目录 → 去父目录找 → 整个产品实验室下都没有 → 再扩大搜索」，
  **全程没有编造内容**。但它是「一直找」而不是「立刻停下问你」，
  如果你觉得该更早停，那是改提示词的事（纯文本，零成本）。
- ☐ **注意按钮发去了哪个会话**：dsh 的会话不一定跟当前工作区同目录。发出去之后左栏会显示
  「已发出「X」→ 会话 NN」，找不到文件夹时按提示换个会话再点。

### C. 叫醒阶梯（D-5，主观，没有自动化能替代）

- ☐ 让 agent 干一件需要你批准的事，然后**把窗口切走去干别的**，感受：
  - 0 秒：托盘换图标 + Dock 角标 + 系统通知 + 宠物切等待动作
  - 8 秒：宠物窗临时置顶摆一下（**不该抢焦点、不该打断你打字**）
  - 30 秒：再通知一次（覆盖前一条）+ Dock 持续弹跳
- ☐ **一动就停**：点通知 / 点托盘 / 窗口获得焦点，三层应该立刻全停。
- ☐ **只叫一遍**：同一个待确认项不该叫第二遍。
- ☐ **过火了就关**：设置 → 用量与预算 → 「卡住时怎么叫你」，四个开关（安静模式 / 8 秒 / 30 秒 / 提示音）。提示音默认关。
- ☐ **托盘五态**：空闲 / 思考中（2 fps 摆尾）/ 等你拍板（角标）/ 已完成 / 出错，外加断线时的灰态「连接不上，正在重试」。
  ⚠ 本机菜单栏项太多，托盘图标被系统折叠了看不见；请在菜单栏项少一些的状态下看，或先隐藏几个其他图标。

### D. 两个跨平台隐患

- ☐ **D-7 macOS 中文目录名 NFC/NFD**：建一个名字带组合字符的工作台包（比如带声调的拼音、或日文浊音「がぎ」），装进去、切过去、**重启鲸坞**，看还能不能选中。
  **宠物包大概率有同样的隐患，顺便一起查。**（这一条我没做，需要真机建目录）
- ☐ **Windows 大小写**：如果你有 Windows 机器，建 `WorkbenchA` 与 `workbencha` 两个包，确认只加载一个并给出 `duplicate-id`。（逻辑已用注入假 fs 直测，真机未验）

### E. 文案检查

- ☐ **skills 空清单**：设置 → 工作台 → 「关于这个工作台」，短视频台的 skills 是空数组，**那一栏应该整个不出现**，连一句占位文案都没有。
- ☐ **agent 预设口径**：任何地方都不该出现「支持 agent 预设」，只能是「已检测到，尚未接通」，而且只在「关于这个工作台」详情里。
- ☐ **未声明许可证**：故意做一个不写 `license` 的包，详情里应该明写「未声明许可证」。
- ☐ **onboarding 观感**（D-10）：纯文本显示丑不丑，能不能接受。

### F. 本机安装状态

- ☑ **本机已装版本 = 最新 Release**：`/Applications/WhaleDock.app` = **v0.5.1**，等于最新 Release v0.5.1。
  用的是**已发布的 Release 产物**（不是本地构建），校验和与 `SHA256SUMS-mac.txt` 逐项核对通过，`codesign --verify --strict` 通过。
- ☑ **硬约束 9**：`mdfind 'kMDItemCFBundleIdentifier == "com.sgd.whaledock"'` 只返回 `/Applications/WhaleDock.app` 一个。
- ⚠ **注意**：v0.6 的工作台功能**不在 v0.5.1 里**。要试 v0.6 得跑源码态 `npm start`，或者等 v0.6 发版。

## 五、三条要你知道的实现取舍

### 1. 拖进主窗口这件事，原方案实现不了，架构换了

原来的主窗口加载的是 dsh 的远程页面且**没有 preload**，`trustedLocalEvent` 要求 URL 精确匹配，
而 dsh 是个路由会变的 SPA——所以那个窗口**永远不可能安全地接 IPC**，也就接不了拖放
（Electron 32 起 `File.path` 已被移除，拿不到路径）。而且拖进去的文件本来就被 `will-navigate` 静默吞掉，
**用户拖了等于什么都没发生，连日志都没有**。

改法：主窗口自己的 webContents 换成本地的 `shell.html`（有 preload、URL 可精确校验、能接拖放），
dsh 搬进一个**同样没有 preload** 的 `WebContentsView` 子视图。远程页面拿不到 contextBridge，
安全边界比以前更紧，而且左侧多了一条常驻的工作台栏——正好是 B-3 稿子里画的样子。

### 2. ⌘⇧1~9 用的是应用菜单加速键，不是 globalShortcut

`globalShortcut` 是系统级抢占，而切工作台是应用内动作。更要命的是
**macOS 的 ⌘⇧3/4/5 是系统截屏**，注册了也抢不过来。所以九个槽位里在 macOS 上有三个是哑的。
好处是多了第四个入口：菜单栏「工作台」，比快捷键更好发现。

### 3. macOS 的更新器只提醒、不安装

看代码才发现：`downloadAndInstallWindowsUpdate` **只在 Windows 非便携版走**，macOS 走的是 `remindOnlyUpdate`。
所以那条从 v0.2 挂到现在的「半自动更新真机验证」**本质上是 Windows 项，在 Mac 上根本关不掉**。

macOS 这一侧能验的部分已经验了，而且是**第一次真·联网验证**：
把本机装回 v0.2.0，它真的去查了 GitHub `releases/latest`，日志里出现 `[app] 发现新版 0.5.1`。
（弹窗本身没截到，多半是被顺手关掉了；那一步留在上面的验收清单里。）

## 六、纸面包验证结论

详见 [`纸面包验证-2026-08-19.md`](纸面包验证-2026-08-19.md)。一句话：

**四个包（律师 / HR / 客服 / 教师）全写出来了，六个原语没有结构性不足。**
预判的三个缺口全部真实出现：输入表单最痛（客服）、批量次之（HR）、多步流程基本不算问题（教师）。
三个都能用「将来加一个可选字段」解决，所以 v0.6 一个都不做。

唯一新增的是 `workspace.json` 里 `folders[].files`——那是你「预置三份示例选题」这条补充要求带来的，
纯增量、复用既有的写文件路径、`schemaVersion` 仍是 1。
