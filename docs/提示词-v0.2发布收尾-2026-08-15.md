【批次 12 · v0.4：多工作区管理 + 截图入口 v1】

2. 截图入口 v1（决策 8：只做入口，不自研"眼睛"）：
   - 三入口：全局快捷键框选（mac 用系统自带 screencapture -i 交互框选，零依赖；Windows 没有等价 CLI，降级为"提示用 Win+Shift+S 后从剪贴板读取"）、拖图进窗、剪贴板粘贴。快捷键默认 CmdOrCtrl+Shift+S，设置窗可改可关。
   - 统一流程：预览确认窗（独立窗口+最小 IPC，可取消）→ 图片落到当前工作区的 鲸坞截图/ 子目录 → 理解层路由按既定优先级：官方视觉 API（尚未开放，预留探测位）→ 已装 vision 插件（探测不到就跳过）→ 本地系统 OCR 兜底（mac 用 JXA ObjC 桥调 Vision 框架 VNRecognizeTextRequest，Windows 用 PowerShell Windows.Media.Ocr，都是系统自带零依赖；OCR 不可用则只落图并给出文件路径）。

【批次 13 · v0.5：桌面宠物 + 皮肤主题（都必须给用户自定义空间，SGD 拍板）】
开工前先做 30 分钟功课：浏览 OpenAI Codex 的 Pet Mode 报道（8 只默认像素宠物按 AI 状态反应、/hatch 一张图生成整套动画、社区分享站）、开源 OpenPets 仓库（MIT，pet manifest 格式、动画帧、agent 状态联动）、以及 Shimeji 系"用户丢 PNG 帧文件夹=一只宠物"的老传统。只借鉴格式惯例与交互思路，不复制任何代码（守零依赖；也别引入任何非 MIT 兼容素材）。

1. 桌面宠物（可自定义的"宠物包"体系）：
   - 壳：独立透明无边框小窗（可拖动、置顶可选、鼠标穿透可选、右键菜单关闭/换宠物），状态由 lib/events.js 驱动：空闲/干活中/等你拍板/完成庆祝/出错，五态。默认关闭，设置窗开启。
   - 宠物包格式（声明式，绝不执行包内任何代码）：userData/pets/<宠物名>/ 下 manifest.json + PNG 图。manifest 只含名字/作者/各状态帧列表/帧率/尺寸锚点等数据字段。缺哪个状态就回落到 idle，不报错。
   - 【关键的零门槛设计】支持"单图宠物"：文件夹里只放一张 PNG（连 manifest 都可省，给默认值），也能当宠物用——漂浮、摇摆、呼吸缩放、事件时的弹跳/晃动这些动画全部由壳用变换统一实现，任何一张图都自动"活"起来。这就是我们对标 Codex /hatch 的平替：用户拿任何 AI 画一张图丢进文件夹即可。进阶用户再用多帧 PNG 做逐帧动画。
   - 内置 2 只官方宠物包当示例与出厂默认：原创像素鲸鱼（从现有图标衍生 sprite，严禁 DeepSeek 官方素材）+ 一只极简款；示例包同时就是格式文档的活教材。
   - 设置窗"宠物"区：开关、宠物包下拉（内置+用户文件夹扫描）、"打开宠物文件夹""重新扫描"按钮。
   - docs/宠物包制作指南.md：大白话教程 + 一段可直接发给任意画图 AI 的"帮我生成宠物帧图"提示词模板；README 邀请用户提 PR 分享宠物包（community-pets/ 目录收录）——这是传播点，认真写。
2. 皮肤主题（可自定义的"主题文件"体系）：
   - 主题=一个 JSON 文件（色板 tokens：背景/表面/主色/强调色/文字等 + 深浅基调 + 可选背景图相对路径），放 userData/themes/ 即被识别；参考 VS Code/Obsidian"用户主题文件夹"的通行惯例；只解析数据字段，不执行代码。
   - 作用域：鲸坞自有界面——启动页、设置窗、看板窗、预览窗、战报卡片配色、宠物窗底色——不注入 dsh 的 Web UI（引擎的脸不动）。
   - 内置 4 套当示例：鲸坞深色（现有品牌色板 #1e2a5e/#4f46e5/#22d3ee 打底）、浅色、极光、墨鲸；跟随系统深浅可选。
   - 设置窗"外观"区：主题下拉即时预览生效、"打开主题文件夹""重载主题"；config 加 theme 字段。
   - docs/主题制作指南.md：改 7 个颜色值=一套皮肤的傻瓜教程；community-themes/ 目录 + README 邀请分享。
3. 安全与边界：宠物包/主题文件都是纯静态资源（图片+JSON），解析要容错（坏文件跳过并在日志说明，不崩溃）；不联网下载包（用户手动放文件夹，社区分享走 GitHub）。
4. smoke（manifest/主题 JSON 解析与回落逻辑纯函数）；版本 0.5.0，文档更新，发布流程同上。
