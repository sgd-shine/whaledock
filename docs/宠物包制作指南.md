# 鲸坞宠物包制作指南

一句话：**往宠物文件夹里新建一个文件夹，丢进一张 PNG，它就是一只会动的桌面宠物。**

不用写配置，不用会画画，不用懂代码。下面从最省事的做法开始讲。

## 一、30 秒做一只宠物

1. 打开鲸坞 → 设置 → **外观与宠物** → 点「打开宠物文件夹」。
2. 在里面新建一个文件夹，名字就是宠物的名字，比如 `柴犬`。
3. 把一张 PNG 图片放进去（建议 128×128、背景透明）。
4. 回到设置，点「重新扫描」，在「宠物包」下拉里选中 `柴犬`，打开「显示桌面宠物」。

完成。它会自己漂浮、轻轻呼吸，AI 干活时动得更快，等你拍板时会晃一晃，任务完成会跳一下。

> 这些动作是鲸坞的壳统一做的，**任何一张图都能动**。你不需要准备动画。

## 二、图从哪来

随便找个画图 AI，把下面这段直接发给它：

```text
帮我画一张桌面宠物用的像素风角色图：
- 主体：一只<换成你想要的角色，比如柴犬 / 小恐龙 / 咖啡杯精灵>
- 正方形画布 128×128 像素，背景必须完全透明（PNG，带 alpha 通道）
- 角色居中偏下，四周留 8 像素空白，不要裁到边缘
- 干净的粗描边、色块平涂，不要渐变、不要阴影投影、不要文字和水印
- 表情自然、正面朝右，方便做成桌面挂件
输出 PNG。
```

拿到图存成 `.png` 丢进文件夹就行。**鲸坞不联网下载任何宠物包**，全靠你手动放文件。

## 三、进阶：多帧逐帧动画

想让它真的走动、眨眼、喷水，就放多张图。有两种方式。

### 方式 A：靠文件名（不写 manifest）

按状态前缀命名即可，鲸坞会自动分组：

```text
柴犬/
  idle-1.png      空闲
  idle-2.png
  busy-1.png      干活中
  busy-2.png
  waiting.png     等你拍板
  celebrate.png   完成庆祝
  error.png       出错
```

五个状态名固定为 `idle` / `busy` / `waiting` / `celebrate` / `error`，用 `-` 或 `_` 接编号。**缺哪个状态就自动回落到 idle**，所以你可以只做 idle 和 busy。

如果文件名一个前缀都认不出来（比如 `a.png`、`b.png`），鲸坞会把它们全部当成 idle 的逐帧动画，一样能用。

### 方式 B：写一个 manifest.json

想精确控制帧顺序、帧率、尺寸和贴边位置，就在文件夹里加一个 `manifest.json`：

```json
{
  "name": "柴犬",
  "author": "你的名字",
  "license": "MIT",
  "frameRate": 6,
  "size": { "width": 128, "height": 128 },
  "anchor": "bottom-right",
  "states": {
    "idle": ["idle-1.png", "idle-2.png"],
    "busy": ["busy-1.png", "busy-2.png", "busy-3.png"],
    "waiting": ["waiting.png"],
    "celebrate": ["celebrate.png"],
    "error": ["error.png"]
  }
}
```

字段全部可省，写错的字段会被忽略并回落默认值，**不会让整只宠物报废**：

| 字段 | 说明 | 默认 / 范围 |
| --- | --- | --- |
| `name` | 下拉里显示的名字 | 缺省用文件夹名，最长 40 字 |
| `author` / `license` | 只做展示 | 各 80 字以内 |
| `frameRate` | 每秒播多少帧 | 默认 6，范围 1–24 |
| `size` | 宠物窗大小 | 默认 128×128，范围 16–512 |
| `anchor` | 初始贴哪个角 | `bottom-right`（默认）/ `bottom-left` / `top-right` / `top-left` |
| `states` | 各状态的帧列表 | 每个状态最多 24 帧 |

### 五态多帧的画图 AI 提示词

```text
帮我做一套桌面宠物像素图，同一个角色的 5 种状态，风格必须完全统一：
角色：<换成你的角色>
规格：每张 128×128 像素，PNG 透明背景，粗描边平涂，角色居中偏下
需要这 5 张，分别命名：
1. idle.png —— 放松站立，眼睛睁开，表情平静
2. busy.png —— 专注干活的样子，可以加一点动作线或小道具
3. waiting.png —— 歪头看着你、头顶一个提示符号，像在等你回答
4. celebrate.png —— 开心庆祝，举手/跳起/头顶星星
5. error.png —— 沮丧或惊讶，眼睛变成 X 或冒汗
5 张必须是同一角色、同一配色、同一比例，只有姿势表情不同。
```

## 四、规则与限制（都是为了安全）

- **只认 PNG**。`.js`、`.html`、`.svg` 一律不读，宠物包里的任何内容都**不会被执行**——鲸坞只读 JSON 数据字段和 PNG 像素。
- 文件名不能包含 `/`、`\`、`:` 等路径字符；指向文件夹外的软链接会被跳过。
- 单张图上限 4 MB、边长上限 2048；单个状态最多 24 帧；一次最多扫描 200 个宠物包。
- 坏文件（坏 JSON、假 PNG、超大图）会被**跳过并写进日志**，不会崩溃，也不影响别的宠物包。
- 设置页会显示「有 N 个宠物包被跳过」，具体原因去日志文件夹看。
- 鲸坞不会为宠物包联网，也不会上传你的图片。

## 五、内置的两只可以直接抄

- `assets/pets/pixel-whale/` —— 像素鲸鱼，完整五态 + manifest，可以当模板照着改。
- `assets/pets/极简鲸鱼/` —— 只有一张 `idle.png`，连 manifest 都没有，就是「单图宠物」的活教材。

两只都是本仓库用 `scripts/make-pet-sprites.js` 程序化生成的原创像素画（MIT）。

## 六、分享你的宠物

做好了欢迎提 PR 到 `community-pets/`：

1. Fork 本仓库，在 `community-pets/` 下新建你的宠物文件夹。
2. 放 PNG（建议同时写上 manifest 的 `author` 和 `license`）。
3. 提 PR，标题写「community-pet: 你的宠物名」。

只接受你自己拥有版权、且明确授权为 MIT 兼容的素材。请不要提交任何公司官方形象、商标或来源不明的图。
